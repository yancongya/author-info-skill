# Resources Directory

This directory stores author-related static resources such as:

- `logo.png` - Author or project logo
- `avatar.png` - Author's avatar/profile picture
- `banner.png` - Banner image for about pages
- `alipay-qrcode.png` - Alipay donate QR code
- `wechat-qrcode.png` - WeChat donate QR code

## Usage

Place your actual image files in this directory and update the paths in `../donate.json` accordingly.

## Recommended Image Sizes

- Logo: 200x200px (square)
- Avatar: 128x128px (square)
- Banner: 1200x400px (recommended)
- QR Codes: 300x300px (square)

## Supported Formats

- PNG (recommended for QR codes)
- JPG/JPEG
- SVG (recommended for logos)
- WebP
