# Author Info Skill

用于存储和检索作者信息的 Agent Skill。

## 安装

```bash
git clone https://github.com/oh-my-outher/author-info-skill.git
```

或者使用 Git 子模块：

```bash
git submodule add https://github.com/oh-my-outher/author-info-skill.git skills
```

## 使用

克隆后在 IDE 中直接使用，试试问：
- **"获取作者的基本信息"**
- **"作者的GitHub是什么"**
- **"如何打赏作者"**

## 数据文件

- `skills/author-info/data/author.json` - 基本信息
- `skills/author-info/data/links.json` - 网站链接
- `skills/author-info/data/donate.json` - 打赏方式
- `skills/author-info/data/resources/` - 图片资源
