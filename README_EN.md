# Author Info Skill

Agent Skill for storing and retrieving author information.

## Install

```bash
git clone https://github.com/oh-my-outher/author-info-skill.git
```

Or using Git submodule:

```bash
git submodule add https://github.com/oh-my-outher/author-info-skill.git skills
```

## Usage

After clone, use directly in your IDE:
- **"Get author basic info"**
- **"What's author's GitHub"**
- **"How to donate to author"**

## Data Files

- `skills/author-info/data/author.json` - Basic info
- `skills/author-info/data/links.json` - Website links
- `skills/author-info/data/donate.json` - Donate methods
- `skills/author-info/data/resources/` - Images
